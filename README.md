# 🧳 AI 避坑检测器（Travel Trap Detector）

> **出行前 10 秒，AI 帮你测出这趟行程 / 这个团 / 这家酒店有没有坑。**

一款面向 18-35 岁年轻出行用户的 H5 工具应用。粘贴一段行程文案、跟团介绍或酒店链接，AI 秒出风险等级与避坑建议；内置趣味「被坑体质测试」，帮你和你的搭子提前排雷。

![界面风格] 柔色波普风 · 暖黄主色 · 纯黑硬描边 · 印章式徽章

---

## ✨ 核心功能

### 1. 行程体检（核心）
- 粘贴行程 / 跟团 / 酒店文案，或输入「目的地 + 报价」
- AI 自动识别低价购物团、强制消费、虚假宣传、自费陷阱等套路
- 输出**红 / 黄 / 绿三档风险仪表盘** + 逐条风险清单（套路名、识别信号、应对建议）
- 目的地避坑提示：匹配内置热门城市知识库或实时检索当地注意事项

### 2. 🧠 被坑体质测试（最受欢迎）
20 道真实旅行情景选择题，从 **4 个维度**测出你的旅行人格：

| 维度 | 左端 | 右端 |
|---|---|---|
| 🧭 信息度 | 攻略党 (P) | 随性党 (F) |
| 🛡 风险感 | 谨慎家 (C) | 冒险家 (A) |
| 👥 角色感 | 领队 (O) | 跟随者 (F) |
| 💰 消费观 | 精算师 (M) | 体验派 (E) |

- **20 种人格**：16 种基础型 + 4 种隐藏稀有型（反套路之王、天选被骗体质、白嫖战神、氪金大佬）
- 每种人格含：4 字母代号、卡通形象、防坑等级、容易踩的坑、最佳旅行搭子、专属防坑建议
- **一键生成分享卡**（PNG），发朋友圈 / 小红书，挑战好友一起测
- **人格图鉴**：收集 20 种类型，隐藏稀有型等你解锁

### 3. 避坑百科
- 10+ 类高频旅行套路知识库，分类浏览 + 关键词搜索 + 收藏
- 每条含：识别信号、风险说明、真实案例、应对建议

### 4. 我的
- 检测历史、我的收藏、人格图鉴收集、举报踩坑入口

## 🚀 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

> 技术栈：React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui + Vite

## ⚠️ 重要说明

本项目原为 **AI 插件驱动的应用**，使用了 `@lark-apaas/client-toolkit-lite` 及 4 个 AI 能力插件（行程风险分类、报告生成、体质测试结果生成、链接抓取）。**这些 AI 能力依赖平台运行时**：

- ✅ 脱离平台后：页面 UI、路由、本地存储、历史记录、收藏、被坑体质测试答题流程、分享卡生成均可正常运行
- ⚠️ 脱离平台后：「AI 检测」按钮会提示失败，需要替换为自有的 AI API 才能使用实时检测能力

如需完全独立运行 AI 检测功能，请将 `src/` 中调用插件能力的部分替换为你自己的 AI 服务接口。
